# CÁC QUYẾT ĐỊNH — CHỌN PHƯƠNG ÁN

Với mỗi quyết định, ghi theo format:

```
## QĐ1 — <tên quyết định>
- Chọn: (a) ... / (b) ... / (c) ... / MỚI: ...
- Độ tin cậy: cao | vừa | thấp
- Bất đồng (nếu có) + điều kiện đổi ý: ...
```

**Các phương án được phép:**

<Liệt kê từng QĐ với các phương án cụ thể — tên file/schema/path chính xác.
Ghi kèm người ủng hộ hiện tại nếu hữu ích: "(D2, D4)" để debater biết mình đang
đổi phe hay theo đa số.>

- **QĐ1 — <tên>:** (a) ...; (b) ...; (c) MỚI.
- **QĐ2 — <tên>:** (a) ...; (b) ...; (c) MỚI.
- ...
- **QĐk — Deferred list:** xác nhận danh sách dưới đây là deferred (đồng ý/không,
  bổ sung mục nào): <...>.

# CAM KẾT CUỐI

- Nếu owner chốt theo đa số ở mỗi QĐ, bạn có sẵn sàng implement/accept không?
- Điều kiện veto duy nhất (nếu có) là gì? (tối đa 1 điều)
- 3 gạch đầu dòng quan trọng nhất bạn muốn owner đọc trong báo cáo cuối.

# ĐỊNH DẠNG TRẢ LỜI (vòng 3)

```
## QĐ1 — ...
...
## QĐk — ...
## Cam kết cuối
```

Viết ngắn gọn: mỗi QĐ tối đa 5 dòng. Tổng tối đa ~1600 từ.
Trả lời bằng tiếng Việt, giữ thuật ngữ kỹ thuật tiếng Anh.
